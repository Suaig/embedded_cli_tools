## 工程定位

`emb` 是面向 STM32/ARM 嵌入式开发的单二进制 CLI，覆盖 Keil 工程解析与编辑、构建烧录、
STM32CubeMX `.ioc` 操作、串口通信与调试。设计目标是给 AI 助手和人类开发者提供
token 高效的工程操作能力（`--ai` / `--json` 三种输出格式）。

架构、模块划分、构建命令与完整命令参考见仓库根目录的 `README.md` 与 `CLAUDE.md`，
本文件不重复。
